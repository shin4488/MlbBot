# ツイート内容の改善案

現状のツイートは、地区順位が地区ごとに6件（毎日）と、ワイルドカード順位がリーグごとに2件（8月以降のみ）。X APIは投稿ごとの従量課金（$0.015/件）のため、ツイート件数が増える案はコスト増とセットで判断する。

```
📅 8/30 ⚾ AL East ⚾ W-L (GB)
1. Yankees 82-53
2. Blue Jays 79-56 (3)
3. Red Sox 76-60 (6.5)
...
#MLB #RepBX #Yankees #BlueJays50 #BlueJays
```

## 1. 使っていないデータの活用

sportsdata.ioのレスポンスには未使用のデータが多い（`TeamStanding` に使用分のみ定義しているため、使うにはプロパティを追加する）。既存ツイートの行末に足す形ならツイート件数は増えず追加コストはゼロ。現状の文面は約180字で、上限280字まで100字ほど余裕があるため、1行あたり数文字〜10字程度の追加なら収まる。

### 連勝/連敗マーク（`Streak`）

3連勝以上のチームにだけ🔥付きで表示する案。毎日変わる情報なので「今日も見る理由」を作れる。全チームに `W1` `L2` まで出すとノイズになるため、閾値で絞るのがポイント。

```
1. Yankees 82-53 🔥W4
2. Blue Jays 79-56 (3)
```

### 直近10試合（`LastTenGamesWins` / `LastTenGamesLosses`）

順位と勢いのギャップ（首位だが失速中・圏外だが急上昇中）が見える。全行に付けると1行あたり約+9字とかさばるため、ワイルドカードツイートの圏外チームだけに付ける等の絞り方が現実的。

```
4. Royals 71-65 (3) L10 7-3
```

### 得失点差（`RunsScored` − `RunsAgainst`）

勝敗以上に地力を表す指標としてMLBファンに馴染みがある。順位と符号がねじれているチーム（勝ち越しなのにマイナス等）が見どころになる。

```
1. Yankees 82-53 +112
```

### 勝率（`Percentage`）

取得・並び替えには使用済みで表示だけしていない。`W-L` から概ね読み取れるため情報が重複気味で、優先度は低い。

どれも同時に載せると行が読みにくくなるため、まず1つ（連勝マークが有力）に絞って追加するのが現実的。

## 2. 表示の遊び・可読性向上（小ネタ）

- 順位を絵文字にする: `🥇🥈🥉` + `4. 5.`、または首位のみ👑
- 前日からの順位変動: 前日データを保持する仕組み（S3に前回結果JSONを置く等）が必要になるが、`↑1` `↓2` は情報価値が高い
- シーズンオフ（順位データなし）の日は現状何も投稿されない。「シーズン開幕まであとN日」ツイートにする案

## 3. AIによる一言コメントの付与（見送り中）

各地区ツイートの末尾に、Claude API（Haiku）で生成した一言コメントを付ける案。

**見送りの判断**: フォロワーの大半は英語圏で日本語コメントは価値が薄く、事実の言い換えにしかならない可能性が高い一方、無人生成のため誤った内容（数字の取り違え等）がそのまま投稿されるリスクと外部依存（Claude API）が増える。効果（エンゲージメント向上）を測る手段も現状ないため、再検討するなら「何をもって効果ありとするか」を先に決める。
