# ツイート内容の改善案

現状のツイートは、地区順位が地区ごとに6件（毎日）と、ワイルドカード順位がリーグごとに2件（8月以降のみ）。X APIは投稿ごとの従量課金（$0.015/件）のため、ツイート件数が増える案はコスト増とセットで判断する。

```
📅 8/30 ⚾ AL East ⚾ W-L (GB)
1. Yankees 82-53
2. Blue Jays 79-56 (3)
3. Red Sox 76-60 (6.5)
...
#MLB #RepBX #Yankees #BlueJays50 #BlueJays
```

## 1. 情報の追加

判断基準は「野球ファンが順位表とセットで知りたい情報か」。順位の数字から読み取れないもの（勢い・優勝争いの見通し）だけを足し、既存の数字の言い換えにしかならないもの（勝率・得失点差など）は足さない。行末への追記ならツイート件数は増えず追加コストはゼロ。現状の文面は約180字で、上限280字まで100字ほど余裕がある。

### 連勝/連敗（`Streak`・要プロパティ追加）

順位が同じでも「今勢いがあるのはどこか」で今日の試合への期待が変わる、毎日更新される情報。3連勝以上のチームにだけ🔥付きで表示し、`W1` `L2` までは出さない（ノイズになるため）。

```
1. Yankees 82-53 🔥W4
2. Blue Jays 79-56 (3)
```

### 直近10試合（`LastTenGamesWins` / `LastTenGamesLosses`・要プロパティ追加）

「首位だが失速中」「圏外だが急上昇中」という順位と勢いのギャップは、プレーオフ争いを追うファンの主要な関心事。全行に付けると1行あたり約+9字とかさばるため、ワイルドカードツイートの圏外チームだけに付ける等の絞り方が現実的。

```
4. Royals 71-65 (3) L10 7-3
```

### 優勝マジックナンバー（既存データから計算可能）

終盤戦のファンの最大の関心は「あと何勝で優勝が決まるか」。地区首位のマジックは `163 −（首位の勝数）−（2位の敗数）` で計算でき、APIのデータ追加は不要。常時表示ではなく一定値以下（例: 20）になったら首位の行末に出すと、点灯自体がニュースになる。

```
1. Rays 92-55 M9
```

どれも同時に載せると行が読みにくくなるため、まず1つに絞るのが現実的。シーズンを通して機能する連勝マークが第一候補で、9月はマジックナンバーの価値が高い。

## 2. 表示の遊び・可読性向上（小ネタ）

- 順位を絵文字にする: `🥇🥈🥉` + `4. 5.`、または首位のみ👑
- 前日からの順位変動: 前日データを保持する仕組み（S3に前回結果JSONを置く等）が必要になるが、`↑1` `↓2` は情報価値が高い
- シーズンオフ（順位データなし）の日は現状何も投稿されない。「シーズン開幕まであとN日」ツイートにする案

## 3. AIによる一言コメントの付与（見送り中）

各地区ツイートの末尾に、Claude API（Haiku）で生成した一言コメントを付ける案。

**見送りの判断**: フォロワーの大半は英語圏で日本語コメントは価値が薄く、事実の言い換えにしかならない可能性が高い一方、無人生成のため誤った内容（数字の取り違え等）がそのまま投稿されるリスクと外部依存（Claude API）が増える。効果（エンゲージメント向上）を測る手段も現状ないため、再検討するなら「何をもって効果ありとするか」を先に決める。
