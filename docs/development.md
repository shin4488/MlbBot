# 開発上の判断と投稿仕様

責務、投稿条件、外部API、失敗時の動作を変更するときに、関連節を確認する。実行権限・検証の必須条件は [開発ガイド](../CLAUDE.md)、構成図は [README](../README.md#プログラムの構成)、運用は [インフラ資料](../infra/README.md)を参照する。

## 判断を置く場所

組み立ては [Program](../TwitterMlbBot/Program.cs)、取得・投稿を続けるかの判断は [BotRunner](../TwitterMlbBot/BotRunner.cs)を入口にする。HTTPクライアントの設定と寿命を起動側で管理し、取得元・送信先を差し替えてテストできるようにする。

API固有の応答形式は `TwitterMlbBot/Mlb/` のクライアント内に閉じ込め、通信なしで解析・検証できる形にする。勝敗の妥当性・順位計算はドメイン側、文面や投稿対象の選択は `TwitterMlbBot/Composing/` に置く。全クラスや呼び出し順は転記せず、変更する処理から実装をたどる。

## 実行日と投稿条件

実行時刻は [Terraform](../infra/environments/prod/main.tf)、投稿の種類・件数・ワイルドカードを含める時期は [TweetComposer](../TwitterMlbBot/Composing/TweetComposer.cs)を正とする。起動は年中行うが、レギュラーシーズン終了日の翌日以降は順位取得・投稿を見送る。

日程は認証不要のMLB公式Stats APIから取得する。応答の先頭ではなくシーズンIDで対象年を特定し、対象なし・複数該当・終了日の年不一致は日程取得失敗として扱う。

| 状態 | 動作と理由 |
| --- | --- |
| シーズン最終日まで | 順位を取得して文面を作る |
| 終了日の翌日以降 | 順位取得・投稿を見送る |
| 日程取得失敗、シーズン中の可能性がある期間 | 投稿を続け、エラーログと監視アラームでメール通知する |
| 日程取得失敗、シーズン外と判断する期間 | 投稿を見送り、警告ログのみで正常終了する。メール通知しない |
| 順位が空 | 投稿せず正常終了する。シーズン開始前の空応答も扱える |

取得失敗時の期間条件は [SeasonCalendar](../TwitterMlbBot/Mlb/SeasonCalendar.cs)、継続・見送りの判断は [BotRunner](../TwitterMlbBot/BotRunner.cs)を確認する。期間の一覧や過去の単発確認結果をこの資料に追記しない。

## 順位と文面

- sportsdata.ioのAll-Star用擬似チーム（リーグ名と地区名が同じもの）を除外する。データがある場合は、重複・球団やリーグの欠落・所属異常を全体で検証し、不完全な順位表は投稿しない。球団拡張・地区再編では `MlbApiClient` の `ValidateTeamCoverage` も見直す。
- 勝率とゲーム差は勝敗から計算し、APIの丸め済み勝率を使わない。ゲーム差の基準は地区首位・ワイルドカードのプレーオフ圏最終枠。定義は `TeamStanding.GamesBehind` に集約する。
- 公式ハッシュタグは `HashtagProvider` が管理する。シーズンごとに変わり得るため、文面変更時に必要なチームだけ確認する。
- `TweetContent.CharacterCount` はtwitter-textの設定に沿う重み付き文字数を扱う。結合絵文字を多めに数える場合があるため、上限超過は警告にとどめて送信を試み、実際の超過はX APIの拒否で扱う。上限・重みの現在値は実装を参照する。

## 送信と失敗時の扱い

- 連続POSTによる503を避けるため、`TwitterApiSender` は投稿間隔を空ける。最後の投稿後は待たない。間隔の値は実装を参照する。
- **応答がなくても投稿済みの可能性があるため、自動再送しない。** Lambdaの関数エラー再試行もTerraformで無効にする。AWS側の重複配信全般を防ぐものではなく、再実行機能を追加するなら投稿の冪等性も設計する。
- 送信例外はその1件の失敗として残りを続ける。全件失敗時だけ `AllTweetsFailedException` でエラー終了し、CloudWatchアラームからメール通知する。
- OAuth署名のUNIXタイムスタンプは切り捨てる。未来のタイムスタンプによる認証拒否を防ぐため。
- 投稿件数やリンクを増やす変更ではX APIの費用も確認する。料金・年間試算は古くなりやすいため固定値を転記しない。
